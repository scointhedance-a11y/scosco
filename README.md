# 診断士一次ドリル

中小企業診断士 第1次試験（7科目）の四択クイズアプリです。ビルド不要の静的サイトで、`index.html` をブラウザで開くだけで動きます。

## 機能

- 7科目（A 経済学・経済政策 〜 G 中小企業経営・政策）から出題科目を選択
- 出題数（5 / 10 / 20 / すべて）と出題範囲（すべて / 未回答のみ / 間違えた問題のみ）を指定
- 問題順・選択肢順を毎回シャッフル。解答後すぐに正誤と解説を表示
- 結果画面で科目別の正答率を表示し、本試験の合格基準（総点60%以上・40%未満の科目なし）に照らした目安を表示
- 間違えた問題だけを解き直し
- 学習記録はブラウザの localStorage に保存（科目別の累計正答率を表示）
- キーボード操作：`1`〜`4` で解答、`Enter` で次へ

## 使い方

```sh
# そのまま開く
open index.html

# またはローカルサーバーで
python3 -m http.server 8000
```

## 問題の追加

`js/questions.js` の `QUESTIONS` 配列に追加します。

```js
{
  id: "A09",            // 科目コード + 連番（重複不可）
  subject: "A",         // A〜G
  q: "問題文",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0,            // 正解の選択肢のインデックス（0始まり）
  exp: "解説",
},
```

追加後は整合性チェックを実行してください。

```sh
npm test   # = node tests/validate.js
```

## 構成

```
index.html         エントリーポイント
css/style.css      スタイル（ライト / ダーク対応）
js/questions.js    問題データ（7科目・56問）
js/app.js          アプリ本体
tests/validate.js  問題データの検証
```
