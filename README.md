# 診断士フレームワーク・ワークベンチ

中小企業診断士試験に登場するビジネスフレームワークを、**実際に書き込んで活用できる** Web アプリです。
事例企業ごとに分析内容を保存でき、計算系のツールは入力すると自動で計算・グラフ化されます。

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動作します（オフライン可）。

```bash
# ローカルサーバーで開く場合（任意）
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages などの静的ホスティングにそのまま公開することもできます。

## 収録フレームワーク（26種類）

| 分野 | フレームワーク |
|---|---|
| 経営戦略 | SWOT分析 / クロスSWOT分析（SWOTを自動参照） / 3C分析 / PEST分析 / 事業ドメイン（エーベル） / ファイブフォース分析（脅威の強さ評価付き） / VRIO分析（競争優位を自動判定） / バリューチェーン分析 / ポーターの3つの基本戦略 / アンゾフの成長ベクトル / PPM（バブルチャートで自動分類） / コトラーの競争地位別戦略 / バランスト・スコアカード |
| 組織・人事 | マッキンゼーの7S / 組織の3要素（バーナード） / 動機づけ・衛生理論（ハーズバーグ） |
| マーケティング | STP分析 / 4P・4C / AIDMA / AISAS / 製品ライフサイクル（段階別の戦略を表示） |
| 運営管理 | 4M分析 / ECRSの原則 / ABC分析（パレート図） / 経済的発注量（EOQ）・発注点・安全在庫 |
| 財務・会計 | 経営分析（収益性・効率性・安全性の18指標を同業他社と比較） / 損益分岐点分析（高低点法による費用分解付き） / 投資の経済性計算（NPV・IRR・回収期間・PI） |

各フレームワークには、1次試験・2次試験（事例Ⅰ〜Ⅳ）で問われやすい **「試験のポイント」** を掲載しています。

## 主な機能

- **事例（プロジェクト）管理**：分析対象の企業ごとにデータを分けて保存（ブラウザの localStorage に自動保存）
- **自動計算・チャート**：損益分岐点図表、PPMマトリクス、パレート図、在庫費用曲線、累積キャッシュフローなど
- **Markdown出力**：フレームワーク単位でコピー、または事例全体をファイルで保存
- **バックアップ**：JSON形式で書き出し・読み込み（別の端末への移行にも）
- **印刷 / PDF**：印刷用レイアウトに対応
- **サンプル事例**：架空の「B社（老舗和菓子店）」で入力例を確認可能
- **レスポンシブ対応**：スマートフォンでも利用可能

## ファイル構成

```
index.html        画面の骨組み
css/style.css     スタイル
js/frameworks.js  フレームワーク定義（項目・試験ポイント）
js/tools.js       計算・チャート系の専用ツール
js/sample.js      サンプル事例データ
js/app.js         状態管理・画面描画・保存
```

フレームワークの追加は `js/frameworks.js` に定義を1つ追加するだけで行えます（`layout: 'grid'` または `'table'`）。
計算を伴うものは `js/tools.js` にツールを実装し、`layout: 'custom', tool: '<ツール名>'` を指定します。

## 注意

- データはお使いのブラウザ内にのみ保存されます。ブラウザのデータ削除で消えるため、定期的にJSONバックアップを取ってください。
- 試験のポイントは学習の補助を目的とした要約です。最新の試験情報・公式テキストもあわせてご確認ください。
