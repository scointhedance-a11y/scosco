# 販売価格シミュレーター

目標営業利益率・固定費・変動費・販売数量から、必要な販売価格を逆算するWebアプリです。

`index.html` をブラウザで開くだけで動作します（外部ライブラリ不要）。

## 計算式

```
販売価格 = (固定費 ÷ 販売数量 + 1個あたり変動費) ÷ (1 − 売上連動費率 − 目標営業利益率)
```

## 機能

- 固定費・変動費を費目ごとに追加／削除
- 決済手数料など売上に比例する費用（%）にも対応
- 価格の端数処理（1円／10円／100円単位で切り上げ）
- 損益計算書、損益分岐点、安全余裕率などの主要指標
- 損益分岐グラフ
- 感度分析（販売数量→必要価格、価格→営業利益）
- 入力内容の自動保存、CSVのコピー
