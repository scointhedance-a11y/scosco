# TOEIC 960 トレーナー

TOEIC L&R で 800 点前後から 960 点を目指すための学習アプリです。ビルド不要の静的サイトで、`index.html` をブラウザで開くだけで動きます（スマホ可）。

## できること

| モード | 内容 |
| --- | --- |
| Part 2 応答問題 | ブラウザの音声合成で読み上げ（米・英・豪・加の発音、速さ調整）。スクリプトは解答後に表示 |
| Part 3/4 会話・説明文 | 設問を先読みしてから音声を聞く。男女で声を切り替え |
| Part 5 短文穴埋め | 分野を選んで出題。1問20秒のタイマーつき |
| Part 7 読解 | 1問1分のタイマーと、読む速度（WPM）の計測 |
| 単語カード | 900点台向けの 150 語を間隔反復（1日→3日→1週→2週→1か月） |
| 間違いノート | 最後に間違えた問題だけを解き直す |
| ミニ模試 | L と R を通しで解き、正答率をスコアに換算 |
| 記録 | 推定スコア、パート別・Part 5 分野別の正答率、直近14日の学習量 |
| 攻略法 | 960点に必要なパートごとの目標と、1日のルーティン |

- 出題は「前回間違えた問題 → 未出題 → 正答率の低い問題」の順に優先されます。
- 選択肢の並びは毎回シャッフルされます。
- 学習記録はブラウザの localStorage に保存されます（端末・ブラウザごと）。
- キーボード操作: `1`〜`4` または `A`〜`D` で解答、`Enter` で次へ、`R` で音声を聞き直し。単語カードは `Space` で表示、`1`〜`3` で評価。

推定スコアは各問題の最新の結果から換算した目安で、公式の換算表ではありません。

## 開発

```sh
npm test                 # ロジックと問題データのテスト（Node.js 18 以上）
npm run build:single     # CSS/JS を 1 ファイルにまとめた dist/toeic960.html を作る
```

問題は `js/data/` にあります。`a` は正解の選択肢番号（0 = A）です。文挿入問題のように選択肢の順番を固定したい問題には `fixed: true` を付けます。
