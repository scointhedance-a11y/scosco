# 水処理ナビ

水処理技術の **学習用クイズ** と、現場で引ける **用語辞書・計算ツール・製品MAP** をまとめたWebアプリです。
スマホ・PCのブラウザで動き、インターネットがなくても使えます。

## 収録内容（現在）

- PAC-2 ボイラ水技術マニュアル Section 2.1〜2.6・2.8〜2.12・2.14〜2.16・2.19・2.20：要点・用語 約290語・クイズ 約230問
- PAC-3 冷却水技術マニュアル Section 3.1〜3.15：要点・用語 約280語・クイズ 約260問
- 製品MAP 2025（Ver.15）：約420製品
- 計算ツール：冷却塔の水収支／濃縮倍数／LSI・RSI／熱量・冷凍トン／薬注量／HTI減衰／HOCl・HOBr割合／LMTD・U値／CaCO₃換算／単位換算

## 使い方

- **いちばん簡単**：`dist/water-app.html` を開く（1ファイルに全部入り。スマホへのコピーや社内共有フォルダに置いて使えます）。
- **ホーム画面に追加（オフライン対応）**：このフォルダを社内Webサーバ等に置き、`index.html` をブラウザで開いて「ホーム画面に追加」。
- 手元で確認：`python3 -m http.server` を実行し http://localhost:8000/ を開く。

学習記録・お気に入りは各端末のブラウザ内に保存されます（「その他」からファイルに保存・読み込み可）。

## 資料の追加

`docs/CONTENT_GUIDE.md` を参照。`content/sections/` にJSONを置いて `python3 tools/build.py` を実行します。
