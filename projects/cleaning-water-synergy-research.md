# 洗浄×水処理シナジー 個人調査（F&B業界ターゲット探索）

## 目的

2027年2月に発足予定の「洗浄＋水処理一体化」組織に向けて、個人の範囲で理解を深め、
発足時にすぐ使える **「洗浄と水処理の一体化：初期仮説メモ」（2〜3ページ）** を用意する。

- 組織発足前のため、大々的には動かない（個人の勉強・情報収集として進める）
- 強み：ネスレの水処理を担当しており、日常業務の中で現場情報が得られる

## 期限・ペース

- 最終期限：**2027-01-15（金）** … 2か月＋年末年始の休み分。2月の発足前に余裕を残す
- 使える時間：週2〜3時間（ばらつきあり、計算上は週2.5h）
- 見積もり合計：18h(仮)　／　期間内の使える時間：約22h（9週×2.5h、年末年始を除く）
- 余裕が少ないため、遅れたら「企業比較を8社→5社に絞る」で調整する

## シナジーの仮説（調査の軸）

| 種類 | 例 |
|---|---|
| 水量の削減 | CIPの最適化ですすぎ水を減らす、回収水をボイラー補給水・冷却塔に再利用 |
| 排水負荷の削減 | 洗剤の選び方でCOD・BOD・窒素・リンを下げる → 排水処理の薬剤費・汚泥も減る |
| エネルギーの削減 | 低温で効く洗浄剤＋熱回収、ボイラー効率 |
| 監視の一元化 | 洗浄と用水・排水のデータを一つにまとめる（Ecolab3D） |
| 窓口の一本化 | 品質保証部門と設備部門の両方に、成果を1社でまとめて約束する |

## ① ネスレ観察チェックシート（日常業務の中で埋める）

⚠️ ネスレの情報は契約・守秘義務の範囲内で、社内の検討にだけ使う。社外に出すときは匿名化するか許可を取る。

| 項目 | 確認すること | メモ |
|---|---|---|
| 水の流れ | 取水 → 用途（ボイラー・冷却・CIP・製品用）→ 排水の量の内訳 | |
| CIPと排水 | CIPの実施時刻と、排水のpH・COD・流量の変動が連動しているか（3D TRASAR等のデータと重ねる） | |
| 洗浄剤の供給元 | どの会社か／どの部門が決めているか | 姫路工場：エコラボ（2026-11-07確認）。決定部門は未確認 |
| 回収・再利用 | 最終すすぎ水・復水を回収しているか、再利用の余地 | |
| 工場の悩み | 排水基準、水コスト、本社の水目標からのプレッシャー | |
| 部門の関係 | 設備・工務と品質保証の連携の度合い | |
| 一体化の効果仮説 | どこで何がどれだけ減りそうか | |

成果物：**水と洗浄のつながりマップ**（工場の水の流れ図に洗浄工程を重ねたもの、A4で1〜2枚）
