## 1. ひとことで言うと

ボイラーの **給水（FW）またはブロー水（BD）を常時サンプリングして水質を測り、その値で薬注ポンプやブロー弁を自動制御する「オールインワン盤」**。
測ったデータは ECOLAB3D（クラウド）に送られ、エコラボの専門部署（SAC / Global Intelligence Center）が 24時間365日 監視する。

- 対象：**工業用・施設用ボイラー**。特に **中〜高圧の蒸気ボイラー**
- 想定顧客規模：年間 **2〜4万ドル**程度の取引（企業によってはもっと大きい）。ピラミッドの「中」〜「大」
- 中核技術：**TRASAR（蛍光トレーサー）** … 薬剤に含まれる蛍光物質を測って「薬剤が実際にどれだけ入っているか」を直接見る

### 測るもの・計算するもの（研修画面より）

**センサーで測る項目（給水）**：TRASAR濃度、pH、導電率、セルファウリング（蛍光計セルの汚れ）、濁度、温度、出力状態、水量計のパルス数

**測定値から計算する項目**：ポンプ稼働率（Pump duty）、薬剤使用量（Product usage）

※ 「Condensate Monitor（復水モニター）」タブもあるが中身は未確認

### サンプリング点と測定項目（Boilers）

ボイラー周りの水の流れ：**給水（Incoming Water Supply）→ ボイラー → 蒸気（工程へ）／ブロー（排水へ）／復水（排水へ）**。状況に応じて、どこを測るのが適切かが変わる。

3DT Boiler には **3つのスタイル** があり、違いは「どこでサンプルを取るか」だけ。

| スタイル | サンプリング点 | 測定項目・条件 |
|---|---|---|
| **給水（Feedwater）** | ボイラー前＝ボイラーに入る水 | pH、導電率、NexGuard（TRASAR）、温度、AT ORP。**高純度モデル：導電率 5〜500 μS/cm ／ 低純度モデル：500 μS/cm 超** |
| **ブロー（Blow-down）** | ボイラー後＝処理済みの出ていく水 | **ボイラー1基ごとに Nalco のブローダウン一式（プローブ・バルブ・継手）の設置が必要** |
| **復水（Condensate）** | ボイラー後＝排水側の流れ | （測定項目は未確認） |

→ 複数缶のサイトでブロー方式を選ぶと、**缶数分のブローダウン一式**が要る（見積もり時の注意点）

### 薬注の制御方式（Chemical Feed & Control Methods）

| 薬剤 | 使える制御方式 |
|---|---|
| **清缶剤（スケール/腐食抑制剤）** | ① TRASAR信号で On/Off または PID ② TRASAR信号と pH でリン酸塩を比例注入 ③ 硬度レベルで On/Off ④ 蒸気流量に比例 ⑤ タイマー ⑥ 手動 |
| **脱酸素剤/不動態化剤（Scavenger / Passivator）** | ① **NCSM信号**で On/Off または PID ② TRASAR信号で On/Off または PID ③ 蒸気流量または TRASAR信号に比例 ④ タイマー ⑤ 手動 |
| **アミン（復水系の防食剤）** | ① 蒸気流量に比例 ② 清缶剤または腐食抑制剤の注入に比例 ③ タイマー ④ 手動 |
| **ブロー制御（Blowdown Control）** | （タブ未確認。マニュアル上は導電率による連続ブロー／定時ブローに対応） |

ポイント：**清缶剤は TRASAR、脱酸素剤は NCSM（腐食の実測値）で制御できる**のが「測って薬を入れる」の中核。アミンは直接測らず、蒸気量や他の薬剤の注入量に連動させる。

### 主な構成機器（Major Components）

| 機器 | 役割 | 補足 |
|---|---|---|
| **コントローラー** | システムの頭脳（主プロセッサ） | All-in-One。ブロー用リレーも内蔵 |
| **蛍光計（Fluorometer）** | サンプル水中の Nalco TRASAR 薬剤の存在（濃度）を分析し、最適な薬剤濃度を保つよう自動調整 | 周辺部品：三方ボールバルブ、蛍光計入口弁、フロースイッチ |
| **SCS（Sample Conditioning System）** | ボイラー水の圧力と温度を、蛍光計に入る前に安全に下げる | 3モデル：**低圧 < 50 psi（3.4 bar）／高圧 50〜1500 psi（3.4〜103 bar）／超高圧 2000 psi（138 bar）**。マニュアルの 0.34／10.3／13.8 MPa に対応 |
| **NCSM（Nalco Corrosion Stress Monitor）** | 給水の腐食レベルを分析する**特許技術（酸化還元）** | 下記参照 |
| **ブロー用リレー** | ブロー弁の制御 | コントローラー内蔵 |
| **通信（ゲートウェイ／モデム）** | ECOLAB3D（または EnVision）サーバーと通信 | 携帯回線または LAN。携帯キャリアは **AT&T（グローバル標準）**、Vodafone は例外的にのみ |

#### NCSM の仕組み

- 測定値は **AT ORP（At-Temperature ORP＝実温度での酸化還元電位）**、単位は **mV**
- 給水の**実際の運転温度・圧力のまま**、正味の酸化還元電位を測って反応する → 給水の「相対的な腐食しやすさ」がわかる
- 常温に冷やして測る一般的な ORP や溶存酸素計と違い、**現場条件そのままの腐食傾向**を見られるのが強み
- 構成部品：サンプル入口弁、圧力計、圧力抜き弁、ORP セル、ORP/RTD（温度）プローブ、参照電極、保護シールド

### 旧3DT Boiler からの変更点（What's changing）

1. **コントローラー**：NXC → All-in-One に変更
2. **リレーボックス**：廃止（リレーはコントローラーに内蔵）
3. **棚（シェルフ）**：廃止

→ 盤がシンプルになり、部品点数が減った

### 新コントローラー（All-in-One＝AIO）の特長

技術の進歩と顧客の期待に合わせて設計し直したコントローラー。

| 観点 | 中身 |
|---|---|
| セキュリティ | ログインID/パスワード、多要素認証、組み込みファイアウォール、**セキュリティ更新をコントローラーへ直接配信** |
| 通信 | 携帯回線（Cellular）、LAN、Modbus |
| ハードウェア | **10インチのタッチパネル**、現場で交換できる入出力基板 |
| 使いやすさ | 設定方法が3通り（本体・モバイルアプリ・ECOLAB3D）、**別の機器から設定をコピー可能**、トレンド表示が2通り（本体・ECOLAB3D） |

## 4. 導入設置のイメージ

- 設置図の略語：BLR ボイラ／DA 脱気器／DP 薬注ポンプ／IN 清缶剤（内部処理）／OX 脱酸素剤（防食処理）／DCS 分散制御システム／BD ブロー弁／CW 冷却水
- **連続ブロー・定時ブローで導電率センサーを使う場合の注意**
  1. ボイラ稼働中、導電率センサー上流のゲート弁は **全開**（通水不良による誤検知防止）
  2. センサー下流の流量調整弁で **背圧をかける** 開度に調整
  3. 蛍光計でブロー管理する場合、サンプル排出点は導電率プローブの位置に置く

### 盤の流れ（外観図 A〜K）

高温高圧のサンプル入口（A）→ サンプルクーラー（冷却水 C→D）→ ストレーナー → 減圧弁・リリーフ弁 → NCSM／フィルター → pH・導電率センサー → 蛍光計 → フロースイッチ → 出口（B、低温低圧）。校正液注入点（J）と校正時の手動排水（K）あり。

## 6. 設置手順のポイント

1. 事前調査に基づき、サンプルライン・断熱・圧力解放ライン・冷却水ラインを用意
2. **接続前にサンプルラインを20分フラッシング**（閉塞防止）。フラッシュラインは必ずドレンへ
3. 電気工事は有資格者のみ。ケーブルグランドで防水を維持。組み立て完了まで電源を入れない
4. ハードワイヤー化する場合は IEC60947 準拠のブレーカーを近くに設置、2.0mm² ケーブル

### 蛍光計の校正（2点：純水＋TRASAR校正液）

1. セルファウリング値が高ければ先に清掃（ブラシ → 落ちなければ希塩酸60mLで2分＋ブラシ）
2. サービス → 校正 → TRASAR薬剤 → 校正する（センサー取付後初回なら YES）→「2点」
3. 入口弁・蛍光計下部弁を閉、出口三方弁をドレン側へ
4. **純水 60mL×3回（計180mL）注入 → 開始**
5. **校正液 60mL×3回注入 → 開始 → 保存**（T3＝赤：S0980、T1＝橙：S0910）
6. 失敗時：液の取り違え・混入・使用期限を確認して再校正
- ブランクに **RO透過水は使わない**（蛍光を持つ可能性）。純水用と校正液用でシリンジを分ける

### 導電率・pHセンサーの校正

- **新品・値が不安定**：2点校正 → その後1点校正
- **定期**：ポータブル計で読み値を確認し、必要なら1点校正
- 2点校正：センサーを外し、校正液2種をそれぞれ別ビーカーで。温度差があれば3〜5分浸漬。導電率センサーは気泡を抜き、撹拌しない。戻すときは **プローブの穴を流れの向きに合わせる**
- 1点校正：通水したまま30分以上待ち、ポータブル計の値を入力。ブロー側は流れを確保（ブロー弁を一時手動で開く等）

## 8.5 NCSM（ORP）のメンテナンス：短絡テスト・参照電極の修復とチェック

> 出典：3D TRASAR Boiler Technology 取扱説明書 **OM0211（JPN）p.73〜80**（抜粋8ページのスキャン、社内用・社外秘）
> ⚠️ これは**旧コントローラー（NXC 世代）の説明書**。画面操作（Actions キー → Calibrate）は NXC のもの。All-in-One では画面が違う可能性が高い（要確認）。電極の扱い・数値基準は共通と思われる。

### NCSM の構造（おさらい）

- **ORP/RTD 複合プローブ**：白金（ORP）電極＋温度（RTD）電極。L字形の繊細な電極
- **参照電極（Ag/AgCl）**：外部圧力平衡型（EPBRE）。0.1N KCl 液に浸った銀/塩化銀ロッドが、テフロンチューブとセラミック膜を介して高温高圧の水に接する
- **3/8インチのステンレス製クロス継手**：これが **ORP セル**。ORP/RTD プローブと参照電極の先端がセルの中央に集まる
- 測定値＝**実温度・実圧力で、白金電極と Ag/AgCl 参照電極の間の電位差（mV）** ＝ AT ORP

### ① 短絡テスト（配線とコントローラーの簡易チェック）

電極にケーブルをつなぐ**前**に実施。

1. メス‐メス BNC（アクセサリーキット付属）で、ケーブルの「ORP」と「Ref」のオス BNC をつなぐ（短絡）
2. コントローラーで Short Circuit Test を実行 → **0 ± 5 mV なら合格**。外れたら配線を確認して再実施
3. 合格したら、Ref → 参照電極、ORP → 白金電極につなぐ

**判断の目安**：還元状態のボイラー給水なら、安定後の NCSM 値は**マイナス**になるはず。
- プラスの値 → まず**電極の逆付け**を疑う
- 正しく付いていてプラス → 系が**酸化側（溶存酸素が多い）**に寄っている。脱酸素剤を増やせば値は下がるはず

### ② 参照電極の修復（リファービッシュ）

- **参照電極は破損防止のため、外した状態で出荷**される → **使う前に必ず修復が必要**
- 修復のタイミング：**立ち上げ時**、NCSM を長く使っていなかったとき、**電極が空気にさらされたとき**
- 必要な道具はすべて NCSM のアクセサリーキットに入っている

**手順の要点**

1. 安全確認：NCSM を隔離・減圧、バルブを固定・操作禁止表示。**セルは時間をかけて冷ます**（気泡防止）
2. 参照電極ベース上部の大きいナットを緩め、内部（テフロンチューブ部）を 1/4インチ SS チューブから引き抜く。**レンチ2本で**（継手ユニオンを押さえながら）、**締めすぎない**
3. テフロンチューブを、挿入部（ベースから約8〜10cm）で**ねじりながら軽い力で**2つに分ける（強く引っ張るとチューブが伸び、セル内で ORP と REF が短絡する）
4. 10mL シリンジと長い針で、古い KCl 液を両方のチューブから全部吸い出す（**針で Ag/AgCl ロッドを傷つけない**）
5. 挿入部に残った古い真空グリースを拭き取る（グリースが KCl 液を汚す）
6. 挿入部に**ごく少量**の新しい真空グリースを塗る
7. 新しい **0.1N KCl 液**を約5mL、針を奥から引き抜きながら注入。**気泡ゼロ**、開口部は液を盛り上げる。下側（短い方）を先に充填して立てておく
8. 2つのチューブを差し込んで1本に戻す。押し込んだときにセラミックから KCl が1〜2滴出れば、**セラミック膜が機能している**証拠
9. はみ出たグリースを拭き取る

- 長いチューブ側：多孔質セラミックの接液部 ／ 短いチューブ側：先細の Ag/AgCl ロッド・ベース継手・BNC
- ⚠️ **電極を長時間大気中に放置しない**（KCl 液に気泡ができて損傷）。修復 → チェック → すぐ配管に戻す

### ③ 参照電極のチェック（Reference Test）

- 実施タイミング：**初めて使うとき、長期使用後、修復した後**
- 方法：修復した参照電極と、アクセサリーキットの**標準参照半電池**を、**同じ飽和 KCl テスト液**に浸して電位差を測る
  - ケーブル接続：Ref → 標準参照電極、ORP → 修復した NCSM 参照電極
- **合格基準：+90 mV ± 10 mV**（温度の影響は小さい：0〜50℃で 2mV 程度）
- 外れたときの原因
  - 充填した 0.1N KCl 液の不良
  - 参照電極の劣化（工場修理が必要）。頻繁に使わなければ数年もつ
  - 修復手順のミス（電極内の気泡など）
  - 標準半電池の不良（飽和 KCl で満たされていない）
  - コントローラーの誤作動

### ④ 取り付けとその他

- 参照電極は**試料ラインのバルブを開ける直前に、最後に取り付ける**電極。クロス継手の**下から**差し込み、高圧フィッティングと同様に締める（締めすぎない）
- ORP/RTD プローブ：取り付け前にイソプロピルアルコールでやさしく清掃。**元と同じ深さ**に正確に戻す（公差が厳しく、ずれると参照電極と干渉）
- 参照電極ハウジングの 1/4インチ SS チューブは薄肉（0.028インチ、長さ約15インチ）→ 締めすぎ厳禁
- ケーブル：4線の RTD ケーブル（コントローラーの RTD 入力へ）と、ORP/Ref ケーブル（pH/ORP 1端子へ。**白線＝ORP（＋）、黒線＝REF（−）**）
- **NCSM とコントローラーの距離が 6 フィート（約1.8m）を超える**場合は、増幅器付きの特別ケーブル（060-BL52XX.88）を使用。増幅器はリチウム電池駆動 → **電池は2年ごとに交換**（コントローラー OFF、ケーブルを外してから）
- 通常運転中も、プローブの外観点検（漏れなど）を定期的に行う

## 9. 主なアラームと対処

**優先順位：インターロック ＞ No Flow ＞ その他**（この2つが出ている間、他のアラームは無効）

| アラーム | 主な原因 | 対処 |
|---|---|---|
| サンプルフロー不足 | フロースイッチが流れを検知しない | 顧客設備の稼働、バルブ、フロースイッチ、ストレーナー詰まり、配線を確認 |
| インターロック Tripped | 顧客設備停止、信号線断線 | 設備・配線確認。未使用ならジャンパー線を確認 |
| 校正によるオーバーライド | 校正失敗 | 再校正、または前回/工場出荷時の校正値に戻す |
| T3/T1 セルファウリング高 | 蛍光計セルの汚れ | セル洗浄、フィルター取付 |
| T3/T1 TRASAR 高/低 | 設定値不適、読み取り不良、薬剤濃度異常 | 設定値見直し、校正・交換、注入量・ヒューズ確認 |
| pH 高 / 導電率 高低 | 設定値不適、センサー不良、pH調整剤・ブロー不良 | 校正・交換、ブロー弁・ヒューズ確認 |
| T3/T1 濁度高 | 気泡、ファウリング | サンプル状態確認、フィルター取付 |
| フェールセーフ | 制御に使う値が設定範囲・時間を超えた | ポンプ/弁が設定のフェールセーフ動作へ移行 |
| タイムアウト | ポンプ/弁が長時間動いても目標に達しない | 同上。設定時間・ブロー系を確認 |
| アナログ入力範囲外 | 3.5mA以下 / 21mA以上 | 接続機器・配線・シールド・外来ノイズ確認 |
| SOM温度 | CPU高温 | 電源OFF、営業担当へ連絡 |
| 通信エラー（IO/蛍光計） | 基板・ケーブル | 基板の差し直し・交換、ケーブル再接続 |
