## 1. ひとことで言うと

ボイラーの **給水（FW）またはブロー水（BD）を常時サンプリングして水質を測り、その値で薬注ポンプやブロー弁を自動制御する「オールインワン盤」**。
測ったデータは ECOLAB3D（クラウド）に送られ、エコラボの専門部署（SAC / Global Intelligence Center）が 24時間365日 監視する。

- 対象：**工業用・施設用ボイラー**。特に **中〜高圧の蒸気ボイラー**
- 想定顧客規模：年間 **2〜4万ドル**程度の取引（企業によってはもっと大きい）。ピラミッドの「中」〜「大」
- 中核技術：**TRASAR（蛍光トレーサー）** … 薬剤に含まれる蛍光物質を測って「薬剤が実際にどれだけ入っているか」を直接見る

## 2. 顧客への価値（研修画面より）

### 3DT Boiler の価値は「4点セット」で初めて出る

研修の主張：**フルソリューションで導入して初めて価値が届く**。次の4つをそろえること。

| 要素 | 中身 |
|---|---|
| **Expertise（専門性）** | 現場担当者（フィールドレップ）が客先で作業をやり切る |
| **Chemistry（薬剤）** | スケール・腐食を最小化する水処理薬剤 |
| **Equipment（装置）** | 薬注を自動で管理 |
| **Digital（デジタル）** | 24×7 の遠隔監視で最適な状態を維持 |

→ 「装置だけ売る」「薬だけ売る」にならないことが競合との差別化（後述の競合比較とつながる）

### 価値の項目別

| 価値 | 中身 |
|---|---|
| **スケール抑制** | TRASAR蛍光測定で、給水中の清缶剤（**NexGuard**）の注入量をリアルタイム制御。オプションの **Hardness Response Program** は給水の硬度上昇を検知して自動で処理を強める（追加機器が必要） |
| **腐食抑制** | **NCSM（Nalco Corrosion Stress Monitor／腐食ストレスモニター）** が給水の腐食傾向を測り、**脱酸素剤・金属不動態化剤の注入量をリアルタイム調整** |
| **自動化（省人化）** | 測定と薬注を自動化。SAC（System Assurance Center）が24×7で監視 |
| **アラームとレポート** | 条件変化・規格外ですぐ通知。パラメータのトレンドで原因究明。The Hub（顧客ポータル）から閲覧 |
| **データセキュリティ** | ログインID/パスワード、多要素認証、ファイアウォール、定期セキュリティ更新 |
| **使いやすさ** | 大型タッチパネル、分かりやすいメニュー、現場交換できる基板 |
| **本体でのトレンド表示** | 過去のトレンドをコントローラー上または ECOLAB3D で確認 |

### 測るもの・計算するもの（研修画面より）

**センサーで測る項目（給水）**：TRASAR濃度、pH、導電率、セルファウリング（蛍光計セルの汚れ）、濁度、温度、出力状態、水量計のパルス数

**測定値から計算する項目**：ポンプ稼働率（Pump duty）、薬剤使用量（Product usage）

### 薬注の制御方式（Chemical Feed & Control Methods）

| 薬剤 | 使える制御方式 |
|---|---|
| **清缶剤（スケール/腐食抑制剤）** | ① TRASAR信号で On/Off または PID ② TRASAR信号と pH でリン酸塩を比例注入 ③ 硬度レベルで On/Off ④ 蒸気流量に比例 ⑤ タイマー ⑥ 手動 |
| **脱酸素剤/不動態化剤（Scavenger / Passivator）** | ① **NCSM信号**で On/Off または PID ② TRASAR信号で On/Off または PID ③ 蒸気流量または TRASAR信号に比例 ④ タイマー ⑤ 手動 |
| **アミン（復水系の防食剤）** | ① 蒸気流量に比例 ② 清缶剤または腐食抑制剤の注入に比例 ③ タイマー ④ 手動 |
| **ブロー制御（Blowdown Control）** | （タブ未確認。マニュアル上は導電率による連続ブロー／定時ブローに対応） |

ポイント：**清缶剤は TRASAR、脱酸素剤は NCSM（腐食の実測値）で制御できる**のが「測って薬を入れる」の中核。アミンは直接測らず、蒸気量や他の薬剤の注入量に連動させる。

## 4. 導入設置のイメージ

- 設置図の略語：BLR ボイラ／DA 脱気器／DP 薬注ポンプ／IN 清缶剤（内部処理）／OX 脱酸素剤（防食処理）／DCS 分散制御システム／BD ブロー弁／CW 冷却水
- **連続ブロー・定時ブローで導電率センサーを使う場合の注意**
  1. ボイラ稼働中、導電率センサー上流のゲート弁は **全開**（通水不良による誤検知防止）
  2. センサー下流の流量調整弁で **背圧をかける** 開度に調整
  3. 蛍光計でブロー管理する場合、サンプル排出点は導電率プローブの位置に置く

### 盤の流れ（外観図 A〜K）

高温高圧のサンプル入口（A）→ サンプルクーラー（冷却水 C→D）→ ストレーナー → 減圧弁・リリーフ弁 → NCSM／フィルター → pH・導電率センサー → 蛍光計 → フロースイッチ → 出口（B、低温低圧）。校正液注入点（J）と校正時の手動排水（K）あり。

## 6. 設置手順のポイント

1. 事前調査に基づき、サンプルライン・断熱・圧力解放ライン・冷却水ラインを用意
2. **接続前にサンプルラインを20分フラッシング**（閉塞防止）。フラッシュラインは必ずドレンへ
3. 電気工事は有資格者のみ。ケーブルグランドで防水を維持。組み立て完了まで電源を入れない
4. ハードワイヤー化する場合は IEC60947 準拠のブレーカーを近くに設置、2.0mm² ケーブル

### BR68xx の自動酸洗浄サイクル（蛍光計セルの汚れ対策）

| 経過 | 動き |
|---|---|
| 0分 | 三方弁で蛍光計をバイパス、酸ポンプ起動。直前の値で制御を維持、アラーム抑制 |
| 0.5分 | ポンプ停止（酸で浸け置き） |
| 10分 | 三方弁を戻す |
| 12分 | 通常運転に復帰（それまでデータはフィルタリング） |

高温アラーム・蛍光計校正中・インターロック/フロースイッチ作動・オーバーライド・通信エラーのときは洗浄が中止される。

### 緊急シャットダウン（BR55xx 基準）

- **電気故障**：電源OFF → 耐熱手袋でサンプル入口・出口弁を閉 → フィルター下のバルブ閉を確認
- **長期停止**：上記＋サンプル水を冷却・排水、**pHセンサーは外してKCl液に浸けて保管（乾燥厳禁）**
- **SIMカードは12か月通信しないと無効**になる → 技術部装置担当へ連絡
- BR68xx の酸漏れ時：電源OFF、周囲をバリケード、現場手順に従い、SDSを手元に

## 8. メンテナンス・校正

### 推奨スケジュール（月1回が基本）

| 対象 | 作業 | 間隔 |
|---|---|---|
| ストレーナー | 清掃（高圧側ドレン弁を2秒開→閉） | 1か月。詰まりやすい場合は起動後1週間は毎日 |
| 蛍光計 | 校正 | 1か月 |
| 導電率センサー | 校正 | 1か月 |
| pHセンサー | 校正 | 1か月 |

### 蛍光計の校正（2点：純水＋TRASAR校正液）

1. セルファウリング値が高ければ先に清掃（ブラシ → 落ちなければ希塩酸60mLで2分＋ブラシ）
2. サービス → 校正 → TRASAR薬剤 → 校正する（センサー取付後初回なら YES）→「2点」
3. 入口弁・蛍光計下部弁を閉、出口三方弁をドレン側へ
4. **純水 60mL×3回（計180mL）注入 → 開始**
5. **校正液 60mL×3回注入 → 開始 → 保存**（T3＝赤：S0980、T1＝橙：S0910）
6. 失敗時：液の取り違え・混入・使用期限を確認して再校正
- ブランクに **RO透過水は使わない**（蛍光を持つ可能性）。純水用と校正液用でシリンジを分ける

### 導電率・pHセンサーの校正

- **新品・値が不安定**：2点校正 → その後1点校正
- **定期**：ポータブル計で読み値を確認し、必要なら1点校正
- 2点校正：センサーを外し、校正液2種をそれぞれ別ビーカーで。温度差があれば3〜5分浸漬。導電率センサーは気泡を抜き、撹拌しない。戻すときは **プローブの穴を流れの向きに合わせる**
- 1点校正：通水したまま30分以上待ち、ポータブル計の値を入力。ブロー側は流れを確保（ブロー弁を一時手動で開く等）

| 校正液 | 高純度 | | | 低純度 | | | | pH |
|---|---|---|---|---|---|---|---|---|
| 1 | 40 | 40 | 600 | 600 | 3k | 3k | 5k | 4 / 7 |
| 2 | 200 | 600 | 3k | 5k | 5k | 10k | 10k | 7 / 10 |

（単位 μS/cm。測定範囲に合わせて組み合わせを選ぶ）

| サンプルフロー不足 | フロースイッチが流れを検知しない | 顧客設備の稼働、バルブ、フロースイッチ、ストレーナー詰まり、配線を確認 |
| インターロック Tripped | 顧客設備停止、信号線断線 | 設備・配線確認。未使用ならジャンパー線を確認 |
| 校正によるオーバーライド | 校正失敗 | 再校正、または前回/工場出荷時の校正値に戻す |
| T3/T1 セルファウリング高 | 蛍光計セルの汚れ | セル洗浄、フィルター取付 |
| T3/T1 TRASAR 高/低 | 設定値不適、読み取り不良、薬剤濃度異常 | 設定値見直し、校正・交換、注入量・ヒューズ確認 |
| pH 高 / 導電率 高低 | 設定値不適、センサー不良、pH調整剤・ブロー不良 | 校正・交換、ブロー弁・ヒューズ確認 |
| T3/T1 濁度高 | 気泡、ファウリング | サンプル状態確認、フィルター取付 |
| フェールセーフ | 制御に使う値が設定範囲・時間を超えた | ポンプ/弁が設定のフェールセーフ動作へ移行 |
| タイムアウト | ポンプ/弁が長時間動いても目標に達しない | 同上。設定時間・ブロー系を確認 |
| アナログ入力範囲外 | 3.5mA以下 / 21mA以上 | 接続機器・配線・シールド・外来ノイズ確認 |
| SOM温度 | CPU高温 | 電源OFF、営業担当へ連絡 |
| 通信エラー（IO/蛍光計） | 基板・ケーブル | 基板の差し直し・交換、ケーブル再接続 |

## 11. 自分用メモ（現場・提案で使える観点）

- **売りの核は「測って→自動で薬注→遠隔で見張る」の一気通貫**。従来の「タイマー注入＋月1分析」との違いを、薬剤の過不足・人手・トラブル早期発見で説明する
- 型番選びの軸：①給水かブローか ②腐食監視（NCSM）が要るか ③清缶剤をTRASARで制御するか（T1/T3）④蛍光計の汚れが多いサイトか（→BR68の自動酸洗浄）
- 現場の手間として残るもの：**月1回の校正（蛍光計・pH・導電率）とストレーナー清掃**、校正用消耗品の補充
- 設置条件のハードル：60kgの盤、冷却水の確保、屋内、高温高圧サンプルラインの施工、電源（外部ブレーカー）、4G電波（外部アンテナ有）
- **洗浄×水処理シナジー調査との接点**：TRASARの「蛍光で濃度を直接測る」考え方や SAC の遠隔監視は、洗浄（CIP）側の見える化にも横展開できるか？ → 仮説メモの材料候補
